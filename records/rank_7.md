# Rank 7 record curves

The ten smallest curves of rank 7 in this collection, in each of four
categories. The same curve often heads more than one list. Every curve here
has proven rank 7, is given by its global minimal model, and carries 7
independent generators, listed below each table.

All heights are natural logarithms. The naive height is
`log max(abs(c4)^3, c6^2)`; the Faltings height is
`-(1/2) log abs(Im(conj(w1) w2))` on the minimal model, the normalization used
by the [Elliptic Curve Rank Leaderboard](https://elliptic-rank.icarm.cloud).
